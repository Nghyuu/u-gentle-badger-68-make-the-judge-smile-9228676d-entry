One line about a small good thing that happened today: a bus driver who held the doors open with his own hand on the button while I ran, then waved off my thanks like he'd done nothing.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

It copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
